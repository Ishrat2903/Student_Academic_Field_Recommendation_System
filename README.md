# Student Academic Field Recommendation System

A Java-based Student Academic Field Recommendation System that analyzes students' academic performance and related information to recommend suitable academic courses/fields.

The system uses a MySQL database to store student information, course information, and course recommendations. A Java application provides the main application logic and a graphical user interface (GUI) for interacting with the system.

---

## Project Overview

After completing high school, students often have to decide which academic field or course would be suitable for them. However, choosing a field can be difficult when students are unsure which options best match their academic performance.

This project aims to provide a data-driven recommendation system that uses students' academic information, including their grades in:

- Mathematics
- Physics
- Chemistry
- Study hours
- Part-time job status
- Other student information

The system processes this information and provides course recommendations based on the available dataset and recommendation logic.
